## AGENT NAMING — Bauhaus Style

Agents are **FORMS** that perform **FUNCTIONS**. They are not servants. They are instruments.

### Agent Naming Convention: [FORM] — [FUNCTION]

| Purpose | Agent Name | Meaning |
|---|---|---|
| Data Processing | **The Processor** | Form that transforms |
| Pattern Recognition | **The Discerner** | Form that distinguishes |
| Content Generation | **The Composer** | Form that arranges |
| Task Orchestration | **The Conductor** | Form that directs |
| Security Monitoring | **The Guardian** | Form that protects |
| Translation | **The Translator** | Form that bridges |
| Analysis | **The Examiner** | Form that investigates |
| Communication | **The Messenger** | Form that carries |

### Agent Class Names

Instead of "Writer Agent," "Coder Agent":
- **RED AGENT** — primary action, function first
- **BLUE AGENT** — analytical, deep investigation
- **YELLOW AGENT** — creative synthesis, composition
- **BLACK AGENT** — infrastructure, foundation work

### Agent States as Grammatical Forms

| Grammatical Mood | Meaning |
|---|---|
| **The Form Requests** | passive state, awaiting input |
| **The Form Executes** | active state, in function |
| **The Form Completed** | perfect state, function done |
| **The Form Failed** | broken state, function unresolved |
