# STYLE 017: Synthwave Sunset - Color Palette Brainstorm

## Creative Color Expansion Ideas for AI Multi-Agent System UI

---

## Concept 1: "Neon Horizon"

A palette that captures the electric tension between day and night — hot pink bleeding into deep purple with warm orange accents.

| Role | Color Name | Hex Code | Usage |
|------|-----------|----------|-------|
| Primary | Electric Magenta | `#FF2D95` | Primary actions, active agent indicators |
| Secondary | Ultraviolet | `#7B2D87` | Secondary elements, depth layers |
| Accent | Sunset Orange | `#FF6B35` | Highlights, notifications, warnings |
| Background Dark | Void Purple | `#0D0221` | Main background, dark mode base |
| Background Mid | Neon Plum | `#1A0A2E` | Cards, panels, elevated surfaces |
| Glow | Hot Pink | `#FF00AA` | Neon glow effects, focus rings |
| Grid Line | Cyan Mist | `#00F5FF` | Perspective grid lines, subtle accents |
| Chrome | Silver Chrome | `#C0C0C0` | Metallic text accents, chrome highlights |

---

## Concept 2: "Chrome Coast"

Chrome and metallic surfaces meet the warm glow of a perpetual 80s sunset — sophisticated yet electric.

| Role | Color Name | Hex Code | Usage |
|------|-----------|----------|-------|
| Primary | Retina Pink | `#FF1493` | Primary CTAs, agent online status |
| Secondary | Deep Violet | `#4B0082` | Sidebar, secondary containers |
| Accent | Molten Orange | `#FF4500` | Error states, urgent alerts |
| Background Dark | Midnight Base | `#120458` | Base layer, canvas background |
| Background Light | Haze Purple | `#1E0A3C` | Cards, floating panels |
| Glow | Neon Rose | `#FF00FF` | Glow effects, hover states |
| Chrome | Polished Chrome | `#E8E8E8` | Metallic icons, chrome text |
| Chrome Shadow | Dark Chrome | `#8A8A8A` | Chrome depth, metallic shadows |

## Concept 3: "Retrograde"

Nostalgic 80s arcade vibes with a modern twist — saturated magentas and purples punctuated by sharp cyan and warm amber.

| Role | Color Name | Hex Code | Usage |
|------|-----------|----------|-------|
| Primary | Hologram Pink | `#FF0080` | Brand color, logo, primary UI |
| Secondary | Deep Space Purple | `#2E0057` | Backgrounds, dark zones |
| Accent | Arcade Amber | `#FFAA00` | Accents, select highlights, badges |
| Background Dark | Synth Black | `#0A0015` | App background, modal overlays |
| Background Mid | Vapor Purple | `#150025` | Panel backgrounds, containers |
| Glow | Laser Magenta | `#FF44CC` | Active states, focus indicators |
| Grid | Electric Cyan | `#00FFFF` | Grid lines, retro accents |
| Chrome | Chrome Silver | `#D4D4D4` | Metallic effects, icons |

## Gradients (for sunset effects)

```
Sunset Horizon:
  #FF2D95 → #7B2D87 → #0D0221

Neon Dusk:
  #FF0080 → #4B0082 → #120458

Retrograde:
  #FF1493 → #2E0057 → #0A0015
```

## Glow Color Formulas (for box-shadow)

- **Hot Glow**: `0 0 20px #FF00AA, 0 0 40px #FF00AA50`
- **Cyan Glow**: `0 0 15px #00F5FF, 0 0 30px #00F5FF50`
- **Amber Glow**: `0 0 15px #FFAA00, 0 0 30px #FFAA0050`
