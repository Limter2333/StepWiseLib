## DESIGN NOTES

- Use monospace fonts for agent names and status codes
- Status indicators should glow (box-shadow with color matching status)
- Grid-line backgrounds suggested for panels
- Sunset gradient accents (pink/purple/orange) for highlights
- "GLOWING" terminology for active/positive states
- "GRID" and "NEON" as dominant terminology anchors
