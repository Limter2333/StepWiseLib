## 1. Concept Overview / 概念概述

**Design Philosophy / 设计理念**
Memphis Design (1980s Italian avant-garde) meets AI Multi-Agent creativity. Bold geometric shapes, playful patterns, and joyful rebellion against boring interfaces.

孟菲斯设计（1980年代意大利前卫设计）与AI多智能体创意的碰撞。大胆的几何形状、俏皮的图案，以及对无聊界面的快乐反叛。

**Core Emotion / 核心情感**
- Fun 趣味
- Play 玩耍
- Joy 欢乐
- Sparkle 闪耀

**Visual DNA / 视觉基因**
- Squiggly lines / 波浪线条
- Bold primary colors / 粗犷原色
- Geometric confetti / 几何彩屑
- Playful asymmetry / 俏皮不对称

## 10. Implementation Notes / 实施备注

### Copy Guidelines / 文案指南

1. **Be playful, not silly** - Fun but professional / 有趣但专业
2. **Use exclamation points liberally** - Excitement is key / 多用感叹号
3. **Keep it short** - Memphis is bold and direct / 孟菲斯风格大胆直接
4. **Mix languages** - Chinese + English creates energy / 中英混合有活力
5. **Break the grid** - Asymmetry is beautiful / 不对称是美

### Do's / 建议

- Use onomatopoeia: ZIP, BOOM, POP, ZAP
- Add playful emojis sparingly
- Include sound effect words
- Reference Memphis design elements in copy

### Don'ts / 避免

- Don't be condescending
- Don't overuse exclamation marks (leave some impact)
- Don't make copy too long for buttons
- Don't sacrifice clarity for fun
