## 1. Concept Overview / 概念概述

**Design Philosophy / 设计理念**
Soft Glam embodies the essence of quiet luxury — understated elegance with a warm, inviting presence. Like candlelight on silk, every interaction feels cherished and intentional. This is glamour that whispers, not shouts.

柔软奢华诠释静谧奢华的精髓——低调优雅，温婉宜人。如同丝绸上的烛光，每一次互动都令人珍惜且充满仪式感。这是一种轻声细语的奢华，而非喧嚣。

**Core Emotion / 核心情感**
- Luxe 奢华
- Opulent 华贵
- Gilded 镀金
- Serene 宁静
- Cherish 珍视

**Visual DNA / 视觉基因**
- Soft gradients / 柔和渐变
- Luminous metallics / 柔光金属
- Delicate florals / 精致花卉
- Velvet textures / 天鹅绒质感
- Champagne gold accents / 香槟金点缀

## 10. Implementation Notes / 实施备注

### Copy Guidelines / 文案指南

1. **Whisper, don't shout** - Soft glamour is understated / 轻声细语，不要喧哗
2. **Use refined vocabulary** - Luxe, Opulent, Gilded, Serene, Cherish / 使用优雅词汇
3. **Embrace pause** - Allow breathing room in copy / 文案间留有呼吸空间
4. **Pair languages gracefully** - Chinese and English complement each other / 中英优雅搭配
5. **Evoke warmth** - Every word should feel like an embrace / 每个字都要有拥抱的温度

### Do's / 建议

- Use words: cherish, gilded, serene, opulent, luxe, radiant, velvet, silk
- Include soft imperatives: "may", "perhaps", "if you wish"
- Add breath marks in spirit: let sentences flow like sighs
- Reference soft materials: silk, velvet, gold, pearls, candlelight
- Use gentle punctuation: ellipses, soft commas

### Don'ts / 避免

- Don't use harsh consonants or aggressive language
- Don't rush the user with urgent imperatives
- Don't use ALL CAPS — it disrupts the serene atmosphere
- Don't make copy too long — brevity is elegant
- Don't sacrifice warmth for formality

### Accessibility Considerations / 无障碍考虑

- Ensure sufficient color contrast despite soft palette
- Provide clear focus indicators
- Use ARIA labels for icon-only buttons
- Maintain readability at all font sizes
