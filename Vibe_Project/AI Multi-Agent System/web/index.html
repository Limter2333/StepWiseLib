💬 Chat API - 聊天与会话管理

Chat API 提供完整的对话管理功能，包括聊天、会话列表、历史记录、意图识别和Token统计。

💬
POST /api/chat/chat
发送消息获取AI回复，支持知识库增强
🌊
POST /api/chat/stream
流式聊天响应，边生成边返回
📋
GET /api/chat/sessions
获取所有会话列表和活跃会话数
🔍
POST /api/chat/intent/detect
识别用户消息意图类型和置信度
请求示例
POST /api/chat/chat
{
  "message": "你好，请介绍一下你自己",
  "session_id": "demo-001",
  "use_knowledge": true
}
响应示例
{
  "answer": "您好！我是AI多智能体系统的智能助手...",
  "session_id": "demo-001",
  "message_id": "msg_xxx",
  "token_usage": {
    "prompt_tokens": 150,
    "completion_tokens": 280,
    "total_tokens": 430
  }
}
📄 RAG API - 知识库检索增强

RAG (Retrieval-Augmented Generation) API 提供文档上传、向量检索、混合搜索等功能。

📤
POST /api/rag/documents
上传文档到知识库，支持PDF/TXT/DOCX
🔎
POST /api/rag/query
查询知识库，返回答案和相关文档片段
📜
GET /api/rag/documents
列出知识库中所有已索引的文档
📊
GET /api/rag/stats
获取RAG系统统计信息
🔀
POST /api/rag/multihop
多跳推理查询，分解复杂问题
📦
GET /api/rag/cache/stats
RAG查询缓存统计
RAG 工作流程
📤
1. 上传文档
PDF/TXT/DOCX
✂️
2. 文档分块
语义 chunking
🔢
3. 向量化
Embedding model
🔍
4. 语义检索
向量相似度
🤖
5. LLM生成
RAG增强回答
🤖 Agent API - 智能体编排

Agent API 提供多智能体系统的核心功能，包括任务路由、代码生成、文档处理、测试生成、项目管理等。

🎯
POST /api/agents/route
智能任务路由，自动分配到合适Agent
💻
POST /api/agents/dev/generate
Dev Agent 代码生成
🔍
POST /api/agents/dev/review
Dev Agent 代码审查
📝
POST /api/agents/doc/generate-readme
Doc Agent 生成README文档
🧪
POST /api/agents/test/generate-unit-tests
Test Agent 生成单元测试
📊
GET /api/agents/status
获取所有Agent状态和统计
🔗
POST /api/agents/context/set
设置Agent共享上下文
📈
GET /api/agents/context/stats
获取上下文统计信息
🤝
POST /api/agents/collaborate/submit
多Agent协作任务提交

📊 Monitoring API - 系统监控

Monitoring API 提供系统健康检查、性能指标、业务统计、告警管理等监控功能。

❤️
GET /api/monitoring/health
系统健康检查
💻
GET /api/monitoring/metrics/system
系统指标（CPU/内存）
🤖
GET /api/monitoring/metrics/agents
各Agent性能指标
📈
GET /api/monitoring/metrics/business
业务指标统计
🚨
GET /api/monitoring/alerts
当前告警列表
📋
GET /api/monitoring/report
完整监控报告
Prometheus 集成

支持 Prometheus 格式导出，可对接 Grafana 等监控平台：

GET /api/monitoring/metrics/prometheus

# 输出示例
# HELP agent_requests_total Total agent requests
# TYPE agent_requests_total counter
agent_requests_total{agent="dev"} 1234
agent_requests_total{agent="doc"} 567
🔧 MCP API - 上下文管理

MCP (Model Context Protocol) API 管理对话上下文，支持添加、查询、清除上下文片段。

➕
POST /api/mcp/context/add
添加上下文片段
📊
GET /api/mcp/context/stats
获取上下文统计
📄
GET /api/mcp/context/segments
获取上下文片段列表
🗑️
POST /api/mcp/context/clear
清除所有上下文
上下文类型
user_preference
用户偏好设置
session_context
会话上下文
system_instruction
系统指令
📋 Task API - 任务管理

Task API 提供任务创建、更新、查询、统计等完整的管理功能。

➕
POST /api/tasks/
创建新任务
📋
GET /api/tasks/
获取所有任务
🔍
GET /api/tasks/{id}
获取任务详情
✏️
PATCH /api/tasks/{id}
更新任务状态
📊
GET /api/tasks/stats/summary
任务统计摘要
任务状态流转
pending
→
in_progress
→
completed
or
failed
